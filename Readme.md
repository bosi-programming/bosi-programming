# About Me | Sobre Mim - Felipe Azevedo Bosi

🇺🇸

I am a senior software engineer at Clutch, a fintech that runs digital account opening for credit unions. I have built web software since 2019, and I hold a PhD in Architecture (and construction).

At Clutch I work on what happens to an account application after the applicant submits it, on both front end and back end. Some of what I built:

- **Form Builder:** adding a field to a custom form went from 3–5 days to 1–2 hours. 137 credit unions use it in the Staff Portal.
- **Business Account Opening:** I designed the front end across both portals, about 42 routes, and built half of it with another engineer. 12 partners have it turned on.
- **Shared libraries:** I designed 4 shared libraries in the front-end monorepo. After I presented the model at a tech talk, 3 other teams adopted it.
- **Faster CI:** I moved the front end from ESLint to Oxlint in one day, which cut CI lint time from 11.4s to 0.95s.
- **Duplicate accounts:** I fixed a race condition that created duplicate accounts in the core banking system. The fix is an idempotency lock, with tests written first and Datadog monitors.
- **LLM ticket skill:** 23 people on more than 10 teams used it to write 650 tickets in 3 months.

Before Clutch, at Luma Health, I built the front-end logging, dashboards and alerts for 2 of the 3 main apps. Daily errors fell from about 10,000 to fewer than 10.

Outside work I maintain [Bosi Programming Skills](https://github.com/bosi-programming/skills), 14 open-source LLM skills for software engineering that install in 5 harnesses. I also write at [felipebosi.com](https://felipebosi.com) about software requirements, LLM coding tools, and code as language.

Contact: contato@felipebosi.com

- **CI mais rápido:** migrei o frontend de ESLint para Oxlint em um dia, e o lint no CI caiu de 11,4s para 0,95s.
- **Contas duplicadas:** corrigi uma race condition que criava contas duplicadas no core bancário, com uma trava de idempotência, testes escritos antes do código e monitores no Datadog.
